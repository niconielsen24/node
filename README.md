# NodeSter

A personal project to practice full-stack development with **Node.js**, **Express**, **TypeScript**, and **React**.

NodeSter is a browser-based implementation of [El Switcher](https://maldon.com.ar/blog/projects/el-switcher/), a turn-based board game. All rights to the original game concept, rules, and design belong to their respective creators. This project is a fan remake made purely for learning purposes — it is not affiliated with, endorsed by, or intended to compete with the original.
